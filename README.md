# Bunty.exe — REAL FINAL V3

This is the corrected V3. It contains a real interactive candle-blowing birthday checkpoint.

## Candle interaction
1. Type a secret wish.
2. Tap **BLOW INTO MIC** and blow into the phone.
3. The Web Audio analyser detects the breath.
4. The flame disappears and smoke appears.
5. The birthday reveal unlocks with confetti, hearts and a chime.
6. **TAP TO BLOW** is included as a fallback if microphone permission is unavailable.

For microphone detection, deploy on HTTPS (for example Vercel) and allow microphone permission. Local file mode may block microphone access, but the fallback works.

Photos are the original supplied photos. No face transformation is performed, and the hand-holding photo is not included.
